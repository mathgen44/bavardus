Installation de Bavardus

Cette page n'est accessible que tant qu'aucun propriétaire n'est enregistré. Le premier compte Twitch qui se connectera deviendra propriétaire de cette instance, et l'installation se verrouillera sur lui.

  1. Créer une application Twitch

    Sur la console développeur Twitch, créer une application. Le nom est libre, la catégorie « Chat Bot ».

  2. Déclarer l'URL de redirection

    Coller exactement cette adresse dans « OAuth Redirect URLs ». Twitch la compare caractère par caractère : un « / » final, un http au lieu de https ou un port oublié suffisent à faire échouer la connexion.

    {{ url_redirection }}

    Elle est construite à partir de base_url dans config.yaml, actuellement {{ base_url }}. Si ce n'est pas l'adresse par laquelle tu accèdes à cette page, corrige-la avant de continuer.

  3. Renseigner les identifiants

    Le Client Secret se génère sur la page de l'application. Il n'est affiché qu'une fois.
